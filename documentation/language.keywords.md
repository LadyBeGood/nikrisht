### Keywords

Keywords are predefined words used by the language to perform internal operations or represent built-in behavior. 

Nikrisht has **13 keywords**. All of them are reserved and cannot be used as [identifiers](#identifiers).

| Keywords                    | Description                |
|-----------------------------|----------------------------|
| `var` `const`               | Variables                  |
| `func` `return`             | Functions & Returning      |
| `if` `else`                 | Conditional branching      |
| `loop` `with` `exit` `skip` | Looping and loop control   |
| `true` `false`              | Boolean Literals           |
| `null`                      | Null literal               |
