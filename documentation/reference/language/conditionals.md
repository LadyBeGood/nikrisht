### Conditionals
Conditionals control which block will be executed based on a **condition**. 

The condition must be a boolean value, Nikrisht does not have truthy or falsy values. 


<!-- #### Conditional statements -->
```
if (age < 13) {
    write("You're a child");
} else if (age > 19) {
    write("You're an adult");
} else {
    write("You're a teen");
}
```
<!-- 
#### Conditional expressions
```
const status = 
    if (age < 13)
        "child"
    else if (age > 19)
        "adult"
    else
        "teen";
``` -->
