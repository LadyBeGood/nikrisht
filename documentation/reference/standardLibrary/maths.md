### Maths

#### `pi`
Constant representing the ratio of the circumference of a circle to its diameter, approximately 3.14159.

#### `remainder(a, b)`
Calculates the remainder of division.
- **Parameters**: 
    - `a` (`number`)
    - `b` (`number`)
- **Returns**: `number`

#### `power(base, exponent)`
Raises a base number to the specified exponent.
- **Parameters**: 
    - `base` (`number`), 
    - `exponent` (`number`)
- **Returns**: `number`

#### `random()`
Generates a floating-point number from `0` (inclusive) up to `1` (exclusive).
- **Returns**: `number`

#### `floor(value)`
Rounds down and returns the largest integer less than or equal to a given number.
- **Parameters**: `value` (`number`)
- **Returns**: `number`

#### `ceil(value)`
Rounds up and returns the smallest integer greater than or equal to a given number.
- **Parameters**: `value` (`number`)
- **Returns**: `number`

#### `round(value)`
Rounds a number to the nearest integer.
- **Parameters**: `value` (`number`)
- **Returns**: `number`

#### `absolute(value)`
Returns the absolute value of a number.
- **Parameters**: `value` (`number`)
- **Returns**: `number`

#### `truncate(value)`
Removes fractional digits from a number, returning the integer part.
- **Parameters**: `value` (`number`)
- **Returns**: `number`

#### `log(value, base?)`
Calculates the logarithm of a number for a given base (defaults to base 10).
- **Parameters**: 
  - `value` (`number`)
  - `base` (`number`, optional) Default is `10`.
- **Returns**: `number`

#### `min(array)`
Finds the lowest value in a numeric array.
- **Parameters**: `array` (`array` of `number`)
- **Returns**: `number`

#### `max(array)`
Finds the highest value in a numeric array.
- **Parameters**: `array` (`array` of `number`)
- **Returns**: `number`

#### `sum(array)`
Calculates the sum of all numbers in an array.
- **Parameters**: `array` (`array` of `number`)
- **Returns**: `number`
