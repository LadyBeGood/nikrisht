### Object

#### `count(target)`
Returns the number of elements in an array or the number of characters in a string or the number of key-value pairs in an object.
- **Parameters**: `target` (`array` | `string` | `object`)
- **Returns**: `number`

#### `has(object, key)`
Checks if a specific key exists within an object/map structure.
- **Parameters**: 
    - `obj` (`object`)
    - `key` (`any`)
- **Returns**: `boolean`

#### `keys(object)`
Returns an array of all keys in the object.
- **Parameters**: `object` (`object`)
- **Returns**: `array`

#### `values(object)`
Returns an array of all values in the object.
- **Parameters**: `object` (`object`)
- **Returns**: `array`
